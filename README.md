# Data methodology

The published copy of the data methodology report: how the Auto, Air, Oil and Gas datasets
are built, five pages each.

**Read it:** https://omaxim.github.io/methodology-report/

**Comment on it:** select any text on the page (or use "Comment on figure") and press
Comment. This opens a GitHub issue in this repository, filled in with the passage and where it
is. Submit it, reload the page, and the comment appears next to the passage. Replies and
resolutions happen on the issue.

This repository holds only the built page. It is written by an automated job from the
report's source; changes made here are overwritten.
